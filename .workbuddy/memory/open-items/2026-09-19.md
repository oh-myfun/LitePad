### B82：CHANGELOG 生成器静默丢提交
- 根因：`git log --pretty=format:` 末条**无尾换行**，`read` 在 EOF 返回非 0 ⇒ 循环体不执行 ⇒
  （新→旧排列下）**区间内最旧的提交整条被丢**。v0.8.0 区间恰好 2 个提交，最旧那个就是 feat。
- 修复：循环条件补 `|| [ -n "$sha" ]`；手动补回 CHANGELOG 小节；加 **B82** 静态守卫。
- 顺带发现：`gen-changelog.sh` 只**前置**新小节、不去重 —— 重跑同一版本区间会得到**两份
  `## vX.Y.Z`**（我核对时踩到，已 `git checkout --` 还原）。核对历史版本请用
  `git show <release-commit>:CHANGELOG.md`。

### B83：pre-push 打印「windres: C:/…」却仍报 cargo 失败
- 0074 只修了「探测被短路」；本条的坑在**探测命中之后**：`C:/msys64/mingw64/bin` 原样写进 PATH，
  MSYS 的 `test` 能吃、cargo（**原生进程** → build.rs → embed-resource）却命中不了 ⇒
  仍 `NotAttempted("windres")`，被钩子误报成「cargo test 未通过」。
- 修复：命中后 `WINDRES_DIR="$(cd "$w" 2>/dev/null && pwd)"` 归一成 `/c/…`；加 **B83** 守卫。
  与同文件 `COREUTILS_DIR` 是同一条教训（同一坑换位置再踩一次）。
