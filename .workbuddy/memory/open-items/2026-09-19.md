## B78 — 参照 VS Code 补齐查找栏七处观感（commit 8d49a6f）

用户七条逐条落地（对 `docs/vscode-reference` 的 findWidget.css / findWidget.ts / sash.css）：

1. **左侧宽度手柄** `.find-sash`（= `.monaco-sash`）：4px、left:0、整条高、`ew-resize`，
   悬停/拖拽才画 2px 高亮线；拖动 = `startW + (startX - clientX)`（钉右上 → 往左拖变宽），
   双击在「默认 470 ↔ 可用最大」间切换（VS Code onDidReset 语义）。不落盘。
2. **折叠按钮变高**：浮层加 `replace-toggled` 类（VS Code 同名），chevron 25 → 53px
   （25+3+25）。**不照抄** `-webkit-fill-available`（结果区能撑 220px，铺满成竖条）。
3. **选区按钮移位**：从 `.find-toggle`（输入框内嵌）挪到 prev/next 之后，改 22×22 扁平
   `.find-sel`；激活环用 `inset box-shadow`（真 border 会在 border-box 下把图标挤成 14px）。
4. **互斥**：选区 ↔ 跨文档，点亮一个 `setAllDocs(false)` / `setSelection(false)`。
5. **结果区常驻**：`results.hidden = !跨文档开关`；空列表渲染 `.find-empty`「无结果」+
   `min-height:22px`；收起时也 `results.textContent = ""`（hidden 不清 DOM，过期命中会带出来）。
6. **两框同宽**：`.find-row-replace .find-field { flex: 0 0 auto }` + JS 写死查找框宽度
   （`syncWidths`，`w<=0` 时不下手）。⚠️ 量早了会过期（setCount 之后查找框又变窄 42px），
   挂 `ResizeObserver` 跟随 + `setCount` 里显式补一次 → `pitfalls/0078`。
7. **替换图标重绘**：匹配块 + 一支/两支箭头。codicon 只有码位没有轮廓（0078 里有记录），字形自绘。

### ⚠️ 本次最重要的发现：`tests/` 从未被类型检查（已实测，52 个错误）

  + **TS2578×4（`@ts-expect-error` 已成空转）** + TS2353/TS2580/TS2740/TS2322 各 1。
- 两个高危点：
  1. `tests/menubar.test.ts:101` 给 `MenuBarCallbacks` 传 **`themeChecked`，该字段已不存在** →
     菜单回调接口改过，测试仍在构造旧形状 mock，**该用例是否验证当前行为存疑**。
