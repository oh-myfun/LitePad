## 三条给下会话的经验（已进 rules/pitfalls）
1. **门禁脚本「退出码 0 + 日志正常」≠ 生效**：本项目已三连（0074 半落盘、0082 静默丢提交、
   0083 打印正确却失败）。改钩子/脚本/生成器后一律**真跑一次 + 回读产物**。
2. **写进 PATH 的探测结果必须 `cd … && pwd` 归一**（`C:/…` 与带 `..` 的原始路径对 shell 与
   原生子进程都是死路）。
3. **注入的 `current_time` 可能过期**（本次报 09-18 22:00，实际是 09-19 23:5x）。
   判断「今天」以 `date` / `git log -1 --format=%ci` 为准。
