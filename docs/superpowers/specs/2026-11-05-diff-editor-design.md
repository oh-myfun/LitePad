# B461 · 文本差异编辑器 + 左侧差异面板 —— 设计

日期：2026-11-05 · 状态：**已定稿，待用户点头后写实施计划**（批准前不写产品代码）
构建者检查跑过一轮，5 条开放问题里 3 条已问过用户、2 条由本文档定死（见 ⑩）。

## ① 意图与为什么

用户原话：「复刻 vscode 的文本差异编辑器，在左侧边栏添加按钮和面板，面板中显示差异编辑器中的差异项，
编辑器尽量复刻 vscode 原有能力，包括标签栏对应的按钮。」

为什么要现在做：B458 已经把「哪些行改了」画在源码档行号右侧那 4px 上（绿=新增、橙=改动、红=被删的缝），
但**改成什么样**看不到 —— 想知道只能自己滚上去跟旧内容比，而旧内容此时已经不在屏上了。
差异编辑器补的就是这一格：左右同屏、按块跳、并且把「改了哪几块」变成一个可以点、可以数、可以跟随光标的列表。

## ② 目标 / 非目标 / 反目标

**目标**

1. 一种新的标签类型「差异标签」：一张标签里左右两栏，标题 `旧 ↔ 新`。
2. 两个数据来源都要：
   - **A 档**：当前文档 vs 它上一次保存的正文（`doc.baseline`，与 B458 同一个值）。
   - **B 档**：任选两个文件对比（VS Code 的「选择以进行比较」+「与与已选项目进行比较」那对入口）。
3. 左侧边栏新增第五块视图「差异」：按**差异块**列出，点击跳到那一块并让两侧同时落位；跟随光标高亮当前块。
4. 编辑器标题栏那排动作键，分组照 VS Code：常用几颗出图标，其余收进「⋯」。
5. 只读性照 VS Code：左只读、右可编辑。

**非目标**

- 三方合并 / merge editor（`conflictdialog.ts` 那套保持现状，本轮不碰）。
- git 集成：LitePad 没有 git 层，基线就是「上次保存」，不假装是 HEAD。
- **内联（单栏）视图**：用户拍板第一版只做并排（⑥·视图 一节留了以后补的位置）。
- VS Code 那套逐字符（`innerChanges`）与「移动代码块」：第一版做到**行级 + 块级**。
- 多文件差异编辑器（`multiDiffEditor`）：面板只列「当前那张差异标签」的块。

**反目标（技术上跑通也算失败）**

- 差异面板变成第二个大纲：条目点了落不准，或跳过去两侧不同步。
- 让用户分不清「右栏改了就写了原文件」还是「这是个副本」⇒ 右栏必须**就是那份文档本身**（脏标记、Ctrl+S、
  标签那颗未保存原点全归它），不许出现第二份真相。
- 把 B458 那 4px 标注拆掉重来或改语义。
- 误触发同步滚动那套（`sync-scroll/*` 的语义是「同一文档两个面板」，这里是两份内容）。

## ③ 约束（现状，已核对）

- 差异内核复用 `src/editor/gutterDiff.ts` 的 `lineDiff(baseline, current)`（前后缀修剪 + LCS 锚点 + 格子预算 250k）。
- 侧栏外壳是注册表制：新增一块视图要动 `src/ipc/api.ts` 的 `DrawerViewName` **和** `src/shell/drawer.ts` 的
  `viewFromSetting` 白名单两处 —— 漏后者不是报错，是**静默回落大纲**（B389 踩过，判据要钉住）。
- 面板模型 `Panel.view` 是**一颗** EditorView；`Tab` 按单颗 `docId` 算脏点/标题/会话/跨窗口在场
  （`src/core/app-state.ts:35`、`src/doc-model.ts:134`）⇒ 本轮最大的接线量在这里（⑧）。
- 会话/多窗口认领/热退出副本三条路径都按 `Tab` 的字段走，新字段一律可空，不许把「没记过」读成「关着」（B392）。
- 颜色 token 复用主题无关的 `:root` 三颗 `--diff-add` / `--diff-mod` / `--diff-del`（B458 续轮定稿）。

## ④ 用户已拍板的（按原样，不是推测）

第一轮四条：

1. 比较对象：**两者都要**（A 档 + B 档）。
2. 承载形态：**独立标签类型**（不是复用分屏两格、也不是面板内临时视图）。
3. 面板粒度：**按差异块列**，点击跳到并选中那块。
4. 「标签栏对应的按钮」指的是：**编辑器标题栏动作键**。

第二轮三条（构建者检查逼出来的，答案会改变做出什么）：

5. A 档左栏**跟着 `doc.baseline` 实时走** ⇒ 按 Ctrl+S 差异自己清空、面板回空态。
   刻意与 4px 标注同一个口径，全应用只有一条「差异 = 还没存盘的改动」。
6. 打开差异标签 = **新开一张**，原标签继续开着（LitePad 本来就支持同一文档多标签共存；
   「原地换脸」并不能避免共存，只会把状态藏起来）。
7. 内联（单栏）视图**第一版不做**，先只做并排。

## ⑤ VS Code 原版事实（读本地源码 `E:\Project\vscode`，1.145.0）

这几条会推翻「想当然」，实现前必须知道：

| 想当然 | 源码里其实是 |
|---|---|
| 并排⇄内联是一排里的一颗图标键 | **不是**：它是「⋯」里 `Diff View` 子菜单（Inline / Side by Side / Automatic / Inline (Temporary)）；`toggle.diff.renderSideBySide` 只进命令面板 |
| 忽略首尾空白是普通开关 | 是一颗**带 toggled 状态**的图标键（`diff-editor-toggle-whitespace` ← `Codicon.whitespace`），toggled 判据 = `config.diffEditor.ignoreTrimWhitespace == false` |
| 上一个/下一个差异用箭头左右 | 图标是 `Codicon.arrowUp` / `arrowDown`；键位 `Alt+F5` / `Shift+Alt+F5`；`F7` 是另一件事（无障碍差异视图） |
| 折叠未改动区只有一条命令 | 三颗：`toggleCollapseUnchangedRegions`（`Codicon.map`）+ `collapseAllUnchangedRegions`（fold）+ `showAllUnchangedRegions`（unfold） |
| 交换左右是 merge 才有的 | text diff 就有：`workbench.action.compareEditor.swapSides`（`Codicon.arrowSwap`） |
| 差异块叫 hunk，带 ±计数和类型 | 叫 **change / `LineRangeMapping`**：只有 original/modified 两段行范围 + `changedLineCount`；插入/删除由 `isEmpty` 推导，没有计数缓存 |
| 侧栏有块级差异列表 | **没有**。SCM 侧栏 `Changes` 是文件级 ⇒ 我们这块面板是 LitePad 自己的设计，对外不能写「复刻」 |
| diff 标签有专属图标 | 未找到图标，只把标题拼成 `"{0} ↔ {1}"`；两侧同名时强制显示描述（`ForceDescription`） |
| 差异两边都只读 | **左只读、右可编辑**（`originalEditable` 默认 false，且它不是用户设置项，是 widget 选项） |

`diffEditor.*` 里本轮落地的子集与默认值：`ignoreTrimWhitespace true`、`renderSideBySide true`、
`renderIndicators true`、`hideUnchangedRegions.enabled false`（+ `contextLineCount 3` / `minimumLineCount 3` /
`revealLineCount 20`）。其余（`diffAlgorithm`、`maxComputationTime`、`showMoves`、`compactMode` 等）本轮不碰。

## ⑥ 方案

**模型**：`Tab.kind = "diff"`，带 `left` / `right` 两个输入描述。

- **A 档**：`left = { docId, 取法 = 实时读 doc.baseline }`、`right = { docId }`。
  右栏就是那份文档的**另一个实例**（可编辑、脏归它），与用户拍板的「新开一张、两张共存」一致：
  原标签与差异标签指向同一个 `docId`，脏点按 doc 算 ⇒ 天然同步，不存在「哪张才代表未保存」。
  关闭差异标签只销毁这个实例，原标签与 doc 都不动（沿用现有 `closeTab` 的实例语义）。
  按 Ctrl+S ⇒ 基线跟上 ⇒ 左右相同 ⇒ 差异清空（④·5）。外部重载同理。
- **B 档**：`left = { path }`、`right = { path }`。右栏开一份正常可编辑 doc；左栏走 ⑩·1 的只读对比缓冲，
  不进「已打开编辑器」那套记账。

**内核**：从 `lineDiff` 再开一个块级出口 `diffBlocks(baseline, current): DiffBlock[]`
（连续改动并成一块；`{ originalStart, originalEnd, modifiedStart, modifiedEnd, added, removed, kind }`）。
gutter 那 4px 继续吃 per-line 标记，两者**同源**，不许各算一遍。

**视图**：一张差异标签 = 左右两颗 `EditorView` 并排，中间一条可拖的分割线。**第一版只有并排**。
- 两侧都是源码档（差异视图不套装饰面：折叠标记会把「到底改了哪个字符」藏起来）；
- 改动行画底色（复用三颗 token），删除行在右栏用占位块、左栏用真行；
- 未改动区可折叠，默认不折（照 VS Code 默认）；
- 「跳块」= 两侧同时落位到各自那段的起始行，走既有显式落位那一类，不靠 scroll 猜；
  落位**绕开**同步滚动账本（⑩·3）。

**面板**：第五块抽屉视图 `diff`。条目 = 一块：`kind 图标 + ±行数 + 首行摘要 + 行号区间`。
- 只在「当前活动标签是差异标签」时有内容，否则空态（文案要说清为什么空，不许一片白）；
- 点击 ⇒ 聚焦那张差异标签并跳到那块；
- 跟随光标高亮当前块，权威侧与闸门见 ⑩·2（复用 B388「活动项 = 包住光标那一节」的口径 +
  「选区驱动重绘要装闸」的教训）。

**标题栏动作键**（差异标签激活时替换面板操作区那排；口径同 B224/B422）：
图标键 = 上一个 / 下一个差异（arrowUp / arrowDown）、忽略首尾空白（whitespace，带 toggled）、折叠未改动区（map）；
「⋯」里 = 交换左右（arrowSwap）、全部折叠 / 全部展开（fold / unfold）、刷新。
`Diff View`（并排⇄内联）子菜单**本轮不给**（④·7）。键位：`Alt+F5` / `Shift+Alt+F5`。

**入口**：
- A 档：标签右键「与上次保存比较」+ 文档菜单同款 + `Ctrl+Shift+D`（与现有键位表不冲突，冲突则退到不设键）。
- B 档：资源管理器与标签条右键「选择以进行比较」/「与已选项目进行比较」（VS Code 那对），
  选中态是一份窗口级状态（同 path 再选 = 取消选择）。

## ⑦ 验收判据（先写死，不许事后编）

- 纯函数：`diffBlocks` 的并块 / 纯增 / 纯删 / 贴文首 / 贴文末 / 空文档 / 全同（返回空表）。
- 契约：`DrawerViewName` 与 `viewFromSetting` 白名单**同一份名单**（漏一格就红，钉住 B389 那条静默回落）；
  标签标题拼接（含两侧同名时补描述）；动作键清单 + toggled 判据；
  `Tab.kind` 的会话字段可空、旧会话缺键不炸；A 档两张标签的脏点同源（同一 `docId`）。
- 真机台 `.tmp/b461-check.py`（CDP + 物理键，深浅各一遍）：
  ① 改 3 处 ⇒ 面板 3 条；② 点第 2 条 ⇒ 两侧都落在那块（量那块行首的视觉 y，容差 ≤ 1 行）；
  ③ `Alt+F5` 连跳次序正确；④ Ctrl+S ⇒ 差异清空、面板回空态、4px 同步清空、原标签仍在且脏点消失；
  ⑤ B 档：左栏敲字进不去、右栏能改且脏标记归它、左栏不弹「外部已修改」；
  ⑥ 关掉差异标签 ⇒ 原标签与 doc 都不受牵连、不留孤儿 doc、不触发同步滚动。

## ⑧ 风险

1. **两颗 EditorView 与 `Panel.view` 单颗模型冲突** —— 本轮最大接线量与工期不确定性。
   计划阶段的**第一个任务**必须先定死落点（给 Panel 加旁路，还是差异标签自带一个子容器），
   再动渲染；定歪一次后面每一处都要返工。
2. 大文件（3MB 级）两栏同屏的代价：`lineDiff` 的 250k 格子预算沿用还是另设一档，实测后再定。
3. 多窗口：差异标签跨窗口认领/搬移没定义过语义 ⇒ 第一版**禁止**（右键那几项不给），文档里写明。

## ⑨ 留给实现时定的

- 折叠未改动区的具体视觉（几行上下文、占位条文案）—— 照 VS Code 默认值起步，目视后再调。
- 面板条目超过一屏时的虚拟滚动是否需要（先用普通列表，实测卡了再补）。

## ⑩ 构建者检查里剩下的两条，本文档定死

1. **B 档左栏不是「一份正常的 doc」**（检查问 3）：它只是一个只读对比缓冲 —— 不注册文件监听、
   不进跨窗口在场广播、不进最近打开、不弹「外部已修改」。若那个 path 恰好已经开着，直接复用它的正文，
   不再读一遍盘。这样 ⑦⑤ 与「不留孤儿 doc」才有唯一解。
2. **光标跟随的权威侧 = 右栏**（检查问 5）：左栏只是对照物，左栏里有选区也不许抢面板高亮；
   侧栏那一列跟着**此刻显示的那张标签**走（2026-11 修订）：切到别的标签后，是差异标签就换成
   那一格的块表，不是就换成「当前标签不是差异编辑器」—— 旧口径「高亮保持最后那块」已废止。
3. 附带一条：A 档 `doc.baseline === null`（热退出副本 / 跨窗口认领那种「只知它脏、不知原样」）时
   **不给打开差异标签**，菜单项置灰并给 tooltip 说明 —— 与 B458「基线未知就整片不画」同口径，
   不把每一行都刷成绿色糊用户一脸。
