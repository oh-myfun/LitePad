# 最近打开（B305）设计定稿

日期：2026-10-19 · 分支：`main`（本轮自带功能分支）· 上一轮：同步滚动 v1（v0.20.0）

## 意图与为什么

用户要在「软件刚打开」或「正在使用」时，有一个省事的途径回到刚关掉的文件，省得每次去磁盘上找。
左栏加一块「最近打开」面板；设置页加一项「保存数量上限」；子窗口不再显示左边栏。

## 目标

1. 左栏第二颗键「最近打开」，与「大纲」互斥展开（同时只露一块）。
2. 名单列**此刻没在任何窗口开着**的文件，从新到旧；点一行走现有打开流程。
3. 行形状 B：主行文件名，第二行淡色目录；悬停浮层给完整路径 + 相对时间。
4. 单条清除（行悬停长出 ✕）与清空全部（标题栏 🗑）。
5. 全机一份名单，跨窗口即时刷新：在子窗口把某文件关干净了，主窗口的名单立刻长出这一条。
6. 设置页「最近打开保留数量」，档位 0/10/20/50/100，默认 20；0 = 停止记录并清空。
   （B323 · 2026-10-21 用户改口径：默认档改成 **50**；写死这一行的用例是
   `tests/recents-settings.test.ts` 里那条「默认档三处同口径」，它同时钉 Rust 的
   `DEFAULT_LIMIT`、设置页标着（默认）的那一档、以及 store 的占位值。）
7. 子窗口（`windowKind === "satellite"`）不显示左边栏。

## 非目标 / 反目标

- **不做**「窗口零标签时的欢迎页列表」。用户确认那是他要的形态（读法二），但先推后；它要拆掉
  「关最后一个标签就补一张未命名」「恢复失败退回空白未命名」「卫星关空即自杀」三条兜底，另立一轮。
- **不做**菜单 / 命令面板入口。本轮唯一入口是左栏那块面板。
- **反目标**：名单绝不伸手关别处的标签。跨窗口这条只做「记账」。历史教训：B157 / B188 之所以把
  「关文档就广播给别的窗口」整条删掉，是因为它演变成「在子窗口关个文件，主窗口同文件标签也被关掉」，
  用户明确否掉。
- **反目标**：不把名单塞进 `settings.json`。`Settings` 没有权威窗口，每个窗口都能整表覆写
  （`saveSettings` 见 `src/toc.ts:81,157,198`、`src/prefs.ts:692`），最后写者赢会把别人写的字段冲掉。
- 退出时仍开着的文件**不算关闭**，不进名单。

## 约束

- 不自动推送、不打 tag、不手动 bump 版本；发布只走 `scripts/release.sh`（需用户显式要求）。
- 交付门禁全套：`npm run typecheck` / `lint` / `format:check` / `node scripts/run-vitest.cjs` /
  `cargo test` / `bash scripts/build-all.sh`，另加真机复现轮。
- 临时文件只写项目 `.tmp/`。
- 注释与界面文案沿用仓库既有中文口径；不写 emoji（图标一律 codicon）。

## 核心机制（已定）

**「文件被关掉了」这件事在 Rust 侧推导，不在各关闭分支里逐条埋点。**

每个窗口在「本窗口可见实例的路径集合」变化时，把这份集合报给 Rust（挂点：
`broadcastDocPresence`，`src/ui.ts:269`，它已经是可见集合变化的唯一广播点，开标签走
`refreshAll`、关标签走 `closeTabById`，两条都调它，覆盖全）。Rust 按窗口 label 记账，
算出全机并集：

- 并集里**消失**的路径 ⇒ 记进名单（`closedAt` = 当时时刻）。
- 并集里**出现**的路径 ⇒ 从名单剪掉（打开即消失，含会话恢复、跨窗口取回）。

于是「子窗口关掉整个窗口 / 关掉最后一个标签 / 标签拖出去又关掉」这些路径全都不必各写一遍，
也不会漏。窗口销毁时（`src-tauri/src/main.rs:89` 的 `WindowEvent::Destroyed` 已有分支）清掉那个
label 的集合：卫星窗口清 ⇒ 它独有的路径消失 ⇒ 记录；主窗口清 ⇒ 同时立 `quitting` 旗标 ⇒
不再记录（对齐「退出时仍开着的不算」）。`RunEvent::ExitRequested` 作进程级兜底。

## 数据与归属

- 存储：`<配置目录>/recents.json`，形如 `{ "limit": 20, "entries": [ { "path", "name", "closedAt" } ] }`，
  线上格式 camelCase，写盘走既有 `atomic_write`（`src-tauri/src/session/mod.rs:184` 的 `save_at` 同族）。
- 名单与上限都由 **Rust 单点持有并写盘**（`AppState` 加 `Mutex` 字段），任何变更广播
  `recents-changed`，前端各窗口只是视图。
- 去重键：`normalize_path(fs::canonicalize(..).unwrap_or(raw))`（`src-tauri/src/commands/mod.rs:111`、`:435`
  既有口径），Windows 上再小写化 ⇒ 同一文件不因写法/大小写占两格。显示用记录时那条原始路径。
- 排序与裁剪：新关的顶到最前；超过 `limit` 裁最旧；`limit === 0` 清空并停止记录。
- 列名单时顺手剔除磁盘上已不存在的条目并落盘（文件被外部删除/挪走的自愈）。
- `Settings.recent_files` 那个空槽（`src/ipc/api.ts:105`、`src-tauri/src/session/mod.rs:21`）本轮**不用、不删**。

## 界面

- 侧栏按钮列加 `#side-recent`（codicon `history`），展开区加 `aside#recent-panel`：
  标题栏「最近打开」+ 计数 `6/20` + 🗑（codicon `trash`），下方 `#recent-list`。
- 行的显隐各自只有一个出口（`setSideOpen` / `setRecentOpen`），两颗键的点亮态在自己那个出口里写，
  与 B195 的「四件事一处收口」同一纪律；打开一块就关掉另一块。
- 悬停走既有提示层：`data-tip` = 完整路径，`data-tip-detail` = 相对时间。
  相对时间文案：`刚刚` / `N 分钟前` / `N 小时前` / `昨天 HH:mm` / `M月D日 HH:mm` / `YYYY年M月D日`。
- 空态两行文案：上限 0 ⇒「已停止记录（上限为 0）」；否则「还没有关掉过的文件」。
- 子窗口：`html[data-window-kind="satellite"]` 隐藏 `#side-shell` 与 `#side-resizer`（与
  `src/styles/global.css:590` 藏菜单栏同款），标题栏那颗整栏显隐键一并隐藏，`toggleToc` /
  `setRecentOpen` 在子窗口直接空转（否则会出现「看不见的面板却被打开、还把设置写了盘」）。
- 设置页「通用」分类加一行「最近打开保留数量」，照 B288 日志级别那对的形状：值不在前端
  `settings` 对象里，走独立 IPC 即时生效（`get_recent_limit` / `set_recent_limit`）。

## 留给构建者决定的部分

面板开合态是否持久化（决定：**不持久化**，每次启动都是关着——它与 `toc_open` 不同类，
名单是历史账，不是窗口外观）；单条清除与清空是否弹确认（决定：**不弹**，名单会自己长回来，
且仓库没有通用确认框，为一个可重建的名单造一出不值）；清空后给一条消息提示。
