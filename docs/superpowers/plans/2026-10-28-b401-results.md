# B401 · 编辑模式六件事（结果）

用户口径（2026-10-28）：「继续完善编辑模式，包括但不仅限于一下问题（部分问题 inknote 没有，
部分问题 inknote 也有，前者优先解决）：1、编辑标题时前面的＃号字体和标题不一致；2、点击链接
会把整个应用占据（无法退出），可改成在新的标签里面打开或者按住 ctrl 点击在系统浏览器中打开；
3、预览/编辑切换按钮放在左上角，并修改图标为 eye/edit；4、html 无法正常渲染（可参考 vscode 的
预览模式）；5、任务勾选框和文本大小和位置未对齐；6、多级无序列表项前面的字符没有差异，且字符
和内容间间距不一致」

一句话：六条全落地；**两条臂**（派生预览 `.md-preview` 与装饰面 `.md-deco`）都改，真机台
38 条判据 **FAILS=0 / MEASURED=13**。

## ① 链接不再把应用顶掉

- 入口 `src/markdown/links.ts`：`classifyHref` 把链接分成四类 ——
  - `http(s)` / `mailto` → **系统默认浏览器**（新 `src-tauri/src/opener.rs`：`ShellExecuteW`，
    Rust 侧再过一遍协议闸，只放这三种）；
  - 本地文件（相对 / 盘符 / UNC / `file://`）→ **应用内开标签**（宿主 `doOpen`）；
  - 纯锚点 → 就地滚，不导航；
  - `javascript:` / `vbscript:` / `data:` / 其它协议 → 什么都不做。
- 派生预览的 click 委托（`preview.ts`）与装饰面的 `mousedown`（`livePreview.ts`）都
  `preventDefault`：**任何情况下 WebView 都不导航**。装饰面：预览档普通点击就开；编辑档要
  **Ctrl+点击**（普通点击那一下是放光标）。
- 锚点认两种写法：`#文末章节`（手写，不带前缀）与 `#h-文末章节`（大纲给的 id）都命中；
  装饰面没有 DOM id，按 `extractToc` 的 slug 反查标题行，把光标送过去并 `scrollIntoView`。

## ② 原始 HTML 真渲染（VS Code 口径 + 消毒）

- `pipeline.ts` 开 `html: true`；`src/markdown/sanitize.ts` 两条臂共用：解析后删
  `script/style/iframe/object/embed/link/meta/base`，剥 `on*`、`javascript:`/`vbscript:`/
  非图片 `data:`；`style` 只给 `<span>` 留 `color` / `background-color` / `border-radius`
  （照 VS Code `markdownRenderer.ts` 的允许表），其它元素一律剥掉。
- 块级 HTML 在装饰面走 `HtmlBlockWidget`（同一个 sanitizer）；HTML 里的链接同样过
  `followLink`，不会导航。

## ③ 悬浮切换键搬到左上角 + eye/edit

- `.deco-edit-fab` 定位从右下改成 `left/top: 16px`；图标换成 codicon
  `eye`（编辑档：点一下去预览）/ `edit`（预览档：点一下回编辑）。真机量到
  fab 相对 `.panel-host` 偏移 **(16, 16)**，30×30。

## ④ 标题编辑时的 `#` 号

- 标题的 `#`（`md-heading-mark`）与标题正文共用同一档字号/字重/字距：真机读数
  **markSize 26.88 = bodySize 26.88、weight 720 = 720**。原先 `#` 落回正文 14px。

## ⑤ 任务勾选框与文字对齐

- 派生预览：`input.md-task` 补 `font-size: inherit` —— `input` **不继承父级字号**，之前
  `1em` 取的是 input 默认 13.33px，比 15px 的正文小一圈；`vertical-align` 从 `-0.18em`
  调到 `-0.06em`。真机量到 **方框 15px = li 15px、方框中心 363.7 vs 正文行中心 363.6**。
- 装饰面：方框 `1em`、`top:50% + translateY(-50%)`，勾的两根边也改成 em 口径（14px 字号下
  方框 14×14、中心正好落在行盒中线）。

## ⑥ 多级无序列表

- 符号不再用字体画（`•`/`◦`/`▪` 三个字墨迹大小不一，居中后「符号↔正文」的间隙忽大忽小），
  改成 **CSS 画** 的三档，命名/顺序与 VS Code 预览一致：`disc`（实心圆）/ `circle`
  （空心圆）/ `square`（实心方），三档同一个 0.3em 盒子。档位由 `previewSets` 挂
  `md-bullet-1/2/3` 类，循环使用。
- 嵌套缩进只认 CSS 的 depth 档（每级 +24px）：**标记前的作者空格整段藏掉**。真机读数：
  一级正文左沿 72、二级 96、三级 120（正好每级 +24），`-    多空格` 那一条与单空格同级
  一样是 72。

## ⑧ 踩到的坑

1. **标题 id 带 `h-` 前缀**：`href="#文末章节"` 在派生预览里怎么点都不滚 —— 大纲给的 id 是
   `h-文末章节`，手写链接不带前缀。`anchorCandidates` 同时给「原文/解码后/加 h- 前缀/解码后
   加前缀」四个候选。
2. **`input` 不继承 font-size**：`width:1em` 解析的是 input 自己的 13.33px，不是父级 15px。
3. **::before 分档样式被基础规则盖掉**：`.md-bullet-2::before` 比基础规则少一个类，
   `background: transparent` 被基础的 `background: var(--md-muted)` 盖回实心（第一版真机
   画成一坨实心圆）。三条分档规则都要写成和基础规则同级或更高特异度。
4. **dev / prod 构建判别**：`cargo build --release` 不带 `--features tauri/custom-protocol`
   时 `tauri` 的 build.rs 判 `dev = true`，应用去连 `devUrl`；台子会拿到一个没有会话、
   没有标签的页面（上一次 FAILS=9 全是这个）。
5. **B394 三条 backlog 的去向**：B394-1（点外链导航走）＝本轮 ①；B394-3（列表外的
   `[ ]` 画成点不动的勾）随 `task-item` 改挂到 `li` + 任务规则只在列表项里生效而消失；
   B394-2（点勾写错行）**本轮没复验**，仍挂 B358 那套 `taskClick` 的账。

## ⑨ 边界（有意没做）

- **`bookmark` 之外的自定义协议**（`vscode://` 等）一律忽略：不交给系统，也不导航。
- **HTML 里的 `<style>` 标签不看**：VS Code 预览也不放；内联样式只给 `<span>` 留三条。
- **装饰面的锚点点击在编辑档要 Ctrl+点击**：与其它链接同一条手势口径（普通点击是放光标）。
- **`doc.readonly` 在源码档仍可写**：B397 之前就有的边界，本轮没碰。
