## 二、图片编辑键：悬停显示在图片右上角

### 病根：悬停真空

B406 把编辑键放在图片**右外侧** `left: calc(100% + 8px)`。宽图撑满正文时：

- 图片右缘 = widget 根盒右缘（1065px 宽，右缘 1118）；
- 按钮落在 1125–1151 —— **根盒之外**（编辑器的右内距里）；
- 按钮默认 `pointer-events: none`，只有 `.md-image-widget:hover` 才放开；
- 指针从图上往按钮走，跨过 1118→1125 这段**既不在根盒、也不在按钮上**的空隙时 `:hover` 丢失
  ⇒ 按钮当场 `opacity: 0 / pointer-events: none` ⇒ 永远点不到。

真机复现（修复前）：分段连续移动后 `pe=none`、`elementFromPoint` 命中 `.cm-content`、
点下去弹窗不出现（`.tmp` 早期探针输出）。

### 修法

`src/spike/deco/deco.css` 的 `.md-deco .md-image-edit-btn`：

- `top: 6px; right: 6px`（贴图片右上角内侧，和路径提示同一个「悬浮才现形」路数）；
- 去掉 `left: calc(100% + 8px)`；
- 补 `z-index: 1` 与 `box-shadow: var(--shadow-lg)`（压在深色截图上仍看得清）。

### 证据（`.tmp/b410-check.py` C 段，修复后 **FAILS=0**）

| 判据 | 宽图（1065×687） | 窄图（33×33） |
| --- | --- | --- |
| 悬停显形 | `opacity=1, pe=auto` | 同左 |
| 按钮矩形落在图片内 | x 1085–1111 ∈ 53–1118 | 570–596 ∈ 568–601 |
| 3px 步长连续移动后 | `pe=auto`、仍显形 | 同左 |
| `elementFromPoint` | 命中 `.md-image-edit-btn` | 同左 |
| 点下去 | 打开 `.image-dialog` | 同左 |
| 指针离开 | 收起（`opacity=0`） | 同左 |

契约用例：`tests/spike-deco-style.test.ts` 的 B406 图片块新增三条 —— `right: Npx`、
**不许**出现 `left: calc(100%`、`z-index: 1`。
