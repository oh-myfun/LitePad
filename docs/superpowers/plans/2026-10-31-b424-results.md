# B424 结果 · 资源管理器多根 + 搜索按根归类

用户口径（2026-10-30，原文）：

> 资源管理器支持打开多个目录（像inknote那样），目前的刷新按钮和打开文件夹按钮互换
> （每个打开的目录有单独的刷新按钮，打开文件夹按钮只需要一个），打开的目录上右键菜单中
> 添加移除目录功能。搜索结果里也按照这个打开的目录进行树状归类：每个打开目录内搜索到的
> 结果放在打开目录项下面，独立打开的文件单独列。

> 可以，关于打开文件夹：做成追加，关闭文件夹菜单改成移除全部目录

照的两处：**InkNote**（`addWorkspaceFolders` = 追加 + 去重 + 落盘；`handleRemoveWorkspaceFolder`
= 纯摘名单，不关标签、不删盘上文件）与 **VS Code** 的多根工作区（每根自己一行、自己的刷新）。

## 切片 1 · 设置层多根（`src-tauri/src/session/mod.rs` + `src/ipc/api.ts`）

- `folder_root: String` → **`folder_roots: Vec<String>`**（顺序 = 侧栏从上到下，空表 = 没开文件夹）。
  归设置不归会话：它是窗口级外观，不属于某份文档。
- 老字段只为「读得上来」留着，前端不再认识它；`load` 里 `migrated()` 做一次迁移
  （`folder_roots` 空且 `folder_root` 非空 ⇒ 迁成第一项），迁移不许覆盖用户后来的选择。
- ⚠️ **B392 / B304 那一族**：老字段带 `#[serde(skip_serializing_if = "String::is_empty")]`。
  少了这一句，「用户把目录全移除了」之后下一次启动老值会把目录**复活** —— 空表与缺格是两件事。
  真机台 G1 钉的就是这一条：落盘后 `"folder_root":` 不再出现在文件里。

## 切片 2 · explorer store 多根（`src/explorer/store.ts`）

- 归属这把尺：`asKey()`（`\`/`/` 归一、去尾分隔符、小写）+ 最长前缀 `ownerOf(path, list)`
  ⇒ `rootOf()`。嵌套的两根（`E:\笔记` 与 `E:\笔记\工作`）归到**最里面**那一根。
- 写侧：`setRoots` / `addRoot`（已在不重复加，返回 false）/ `removeRoot` / `hasRoot`。
  摘一根时 `dropUnowned()` 只清缓存里不再属于任何根的那些条目，别的根的展开态照旧留着。
- `loadDir` 的守卫从「等于根」换成「属于某根」，`refreshRoot(path)` 只刷那一根 + 它自己展开的层
  ——多根之后刷新**得有主语**，这是那颗键搬到行里的理由。
- 动作侧（改名 / 回收站 / 粘贴 / 移动）统一走 `anchorFor(path)` 把**归属的那一根**当锚传给 Rust。
  `commands/explorer.rs` 的 `guard_within(root, path)` 只做「别逃出这根」⇒ **一个 Rust 签名都没改**。

## 切片 3 · 面板：每根一行、每根自带一颗刷新（`src/explorer/panel.ts` + `index.html`）

- `renderTree` 循环成 `explorerTree.append(rootRow(root, open), rootChildren(root, open))`；
  根收起/展开的足迹留在视图侧（`rootsCollapsed` 是黑名单，不进 store）——store 那份 `expanded`
  只管根**下面**的目录层。
- 头部那一排四颗：新建文件 / 新建目录 / **打开文件夹** / 全部折叠。B327 定的「打开文件夹 + 刷新」
  两颗并排**互换**了角色：`#explorer-refresh` 从 HTML 删掉，刷新键由 JS 长在每一根那一行的最右
  （`rootRefreshBtn`，`aria-label="刷新该文件夹"`）。
- `parentPathOf` 那截灰字、`setTextTip` 两档提示都跟着改：根行的提示念**完整路径**，
  不是文件名。

## 切片 4 · 追加、移除、启动回放

- 「打开文件夹」`promptOpenFolder`：`openDialog({ directory: true, multiple: true })` ⇒ 一次可选多根，
  每根走 `addFolder`（追加 + 记进「最近打开」的文件夹桶 + 落盘）；一根都没添上就不重画。
- **拖入目录**（B333 那条路径）同样换成追加；「最近打开 ▸ 文件夹」条目那点下去也是追加一根。
- 根那一行的右键菜单：`刷新该文件夹` / **`移除目录`** —— 只动名单，标签一个不关、盘上一个字节不动
  （照 InkNote）。真机 G4 逐条量过。
- 空白处与文件菜单的「关闭文件夹」改名 **「移除全部目录」**（`closeFolder` = `setRoots([])`）。
  命令 id 留着 `file.closeFolder` ⇒ 用户自己配过的键位不丢（改文案不该把键位弄丢，改 id 才会）。
  没开文件夹时它照 B331 的口径置灰不藏。
- `src/main.ts` 启动回放读 `folder_roots` 整表（旧单根由 Rust 那侧迁好，前端不再认）。

## 切片 5 · 搜索多根扇出 + 按根分节（`src/search/store.ts` + `panel.ts`）

- 扇出：每次搜**每根一发** IPC（`Promise.allSettled`），`diskArgs(root)` 逐根组参数。
  部分失败 ⇒ 那一节整个缺席 + 说明行点名（`「乙」没搜成：…`），其余结果照用；
  **全都**没搜成才算一次失败，原话进计数行（与单根时代同一行为）。
- 节的顺序由 `searchedRoots` 这一屏快照定死（搜的时候有几根就定几节），中途再添加一根不会
  把已经画出来的结果重排。
- 归属：`ownerOf(f.path, roots)` ⇒ 每个文件组带一个 `root`（null = 不归任何打开的目录）；
  `sectionsOf(groups, roots)` 把节算成模型的一部分，**视图只读这一份**，不再拿路径猜。
  不属任何根、但正开着的文档自成一节，标题「单独打开的文件」，排最后。
- 节头那一行：目录名 + 灰字念**上一层**（`parentPathOf`，盘根补尾分隔符）+ 该节文件数；
  完整路径走提示。
- **只有一节且不止搜过一根时仍要画节头** —— 判据问的是「搜过几根」（新导出的
  `searchedRootCount()`），不是「剩下几节」：某一根没搜成会让它那一节整个缺席，按节数判
  就把「这一根没搜成」演成了「这里头什么都没有」。
- 单根 / 没开文件夹 ⇒ `list.length === 1 && !headed` 那条路径**一个包装都不加**，
  文件行仍直接进 `#search-results` ⇒ B423 刚定的右沿几何与全部旧选择器照旧成立。

### 用例抓出来的两条真病灶（都不是测试写错）

1. **根外那份开着的文档被列了两遍**：磁盘那一发命中它 + 「单独打开的文件」又扫它一遍
   ⇒ `planReplace` 会替两个文件组各下一次写。修：合并进 `Map`，键 = `normPath`，磁盘先来先占。
2. **嵌套两根时同一文件计两次**（两根各一发都命中 `E:\笔记\工作\a.md`）⇒ 计数与替换名单双份。
   修：合并后按 `ownerOf(...)` 归到最深那一根，`files` / `matches` 从去重后的表重算。
