## B422 · 标签区右侧的 × 换成组菜单「…」（v0.25.10）

### 条目与顺序

操作区最右那颗 ×「移除该分屏」换成 VS Code 编辑器组标题的 More Actions「…」（`codicon-ellipsis`，
`aria-haspopup=menu`，提示「更多操作 · 关闭 / 分屏 / 最大化 / 解散组」）。条目顺序照
`editor.contribution.ts` 的 `MenuId.EditorTitle` 分组：

| 组 | 条目 | 落点 |
| --- | --- | --- |
| `3_open` | 显示已打开的编辑器 | `showQuickPick` 列本组标签 ⇒ `switchTab` |
| `4_split` | 左右分屏 / 上下分屏 | `splitPanelWithTab(panelId, "h"/"v", own, false, true)` |
| `5_close` | 全部关闭 / 关闭已保存 | `closeTabsSequentially` |
| `8_group_operations` | 最大化组 ⇄ 取消最大化组 | `toggleMaximizePanel`（唯一一组时不给） |
| — | 解散组（卫星窗口唯一面板 = 关闭子窗口） | `closePanelById`（唯一一组时置灰） |

- 「解散组」就是旧 × 那条动作（标签并入相邻格后摘掉这一格），补上被换掉的那颗键；
  VS Code 那边叫 Close Group、挂在标签右键，LitePad 收进组菜单。
- 用户拍定**不做**：锁定组（Lock Group）。「关闭其他 / 关闭右侧 / 复制路径」不重复搬
  （标签右键菜单里已经有）。
- B71 那颗最大化中的「还原」键（`screen-normal`）保留 ⇒ 退路不只藏在菜单里。

### 真机抓到的一形：菜单条目是渲染时的快照

第一轮台子 L4 红了：改脏 `a.md` 之后点「关闭已保存」，`b.md` 过了两三秒才消失、`a.md` 反而没关。
根因不在异步，在**判据的取值时机**——操作区只在结构变化时重建，`groupMenu` 是那时算好的数组：
名单里 `a.md` 还算「已保存」⇒ 一发 `closeTabsSequentially([a.md, b.md])` 撞上 `a.md` 的三选一弹窗，
整条链卡在弹窗上，后面 L5–L7 全串不成形。

修（两处，都在点击那一刻才求值）：

- `PanelRenderData.groupMenu` 改成 `MenuItem[] | (() => MenuItem[])`，`panelDataOf` 送
  `() => groupMenuOf(p)`；`buildPanelOps` 里 `typeof src === "function" ? src() : src`。
- 「关闭已保存」的名单再往里收一层：`savedNow()` 在 `onSelect` 里现取 ⇒ 菜单开着的时候用户还能敲字。
- 「能不能解散这一格 / 解散等不等于关窗」抽成 `panelCloseFact()`（渲染快照与组菜单同源，
  不再两处各写一遍）。

### 判据

- 单测：`tests/splitview.test.ts` B422 四条（弹条目 / 置灰 / `onSelect` 一发 / 再点收起 / 空菜单不弹）
  + 新增「给函数 ⇒ 每点一次重算一次」；`tests/satellite-lifecycle.test.ts` 的源码契约改成认
  `panelCloseFact`（并钉住「快照里不许再算一遍 `countLeaves(layout) > 1 ||`」）；
  `tests/smoke.bootstrap.test.ts` 认操作区只剩一颗「更多操作」。
- 真机 `.tmp/b422-probe.py` L1–L8 **FAILS=0（24 条）**：
  L1 键本体（ellipsis、无 ×、`aria-haspopup=menu`）· L2 七条按序 · L3 快速选择列本组两张 + 带勾 + 选中即切 ·
  L4 只关不脏的那张（各格 `[['a.md'], ['c.md']]`）· L5 最大化挤成 0（宽度 `[1125, 0]`）、菜单改口、
  还原键在、取消后 `[563, 563]` · L6 解散并成一格且一个都没关、唯一一组时不给「最大化组」+「解散组」置灰 ·
  L7 左右 / 上下分屏各添一格（2 → 3）· L8 重开一局「全部关闭」清空该组（LitePad 的树规约：空组摘掉），
  另一组不受影响。
- ⚠️ 台子坑（这一轮新踩的，都记进探针头注释）：面板 `data-panel-id` 从 **1** 起、解散后活下来的
  那格 id 会变 ⇒ 一律盯 `.layout-panel` 第一个；脏标记类名是 `tab-dirty` 不是 `dirty`；
  `cdp.ev` 返回裸字符串不能再过 `jload`；关标签是异步的 ⇒ 动作之后等 DOM 形状（`settle`），
  别拿固定 sleep 当同步点；锚点带 `anchorToggle`，菜单还开着时再点它就是**收起** ⇒ 每次点开前先
  Escape 掉残留。
- 卫星窗口的「关闭子窗口」那一档：源码契约钉住，本轮台子未真开第二个窗口去点。

## B423 · 结果行的「替换 / 清除」贴右沿（v0.25.10）

- **根因**（量出来的，不是猜的）：撑右沿的活全压在命中数徽标的 `margin-left: auto` 上，
  而徽标在悬停时要让位给动作键（B419 定的）⇒ 一让位就没人撑了，两颗键停在文件名后面
  ——真机量到距行右沿 **49px**。命中行没这问题：那边的灰字格本来就是 `1 1 auto`。
- **修**：`src/styles/preview.css` 的 `.search-rel` 从 `0 1 auto` 改 `1 1 auto`（吃掉剩余宽度），
  动作条 `.search-row-actions` 不吃 `auto` 边距（两处都撑会把徽标存在时的键又推到中间）。
- **判据**：`tests/search-panel.test.ts`「B423 · 结果行的『替换 / 清除』要贴右沿」两条
  （灰字格必须带 `1 1 auto`；动作条的 `margin-left` 不许有 `auto`）；
  真机 L9：悬停文件行 ⇒ 动作条 `display=flex`、**距行右沿 6px**（= 行内距，修前 49）。
