## B427-1 · 跨根粘贴：一个锚点管两头

**病灶**：`copy_entry` / `move_entry` 只有一个 `root` 参数，store 传的是**源**归属的那一根：

```ts
copyEntry(anchorFor(item.path), item.path, destDir, destAnchor)  // 现在
copyEntry(anchorFor(item.path), item.path, destDir)              // 之前：目标只能被源根校验
```

于是 Rust 拿源锚点去 `within` 目标路径 —— 跨根**一律**被挡成「目标层不在已打开的文件夹内」。
B424 的注释与 UI 文案都写着「打开目录之间」支持，实际从来没成立过（同一根内粘贴是好的，
掩盖了这一格）。

**修法**：两端各认各的锚点，两道闸各管各的地盘：

```rust
fn guard_dest(dest_root: &str, dest: &Path) -> Result<(), String> {
    if dest_root.is_empty() || has_parent(dest) || !within(Path::new(dest_root), dest) {
        return Err(format!("目标层不在已打开的文件夹内：{}", dest.to_string_lossy()));
    }
    Ok(())
}
```

`dest_dir_of` = **先验归属、再验存在**。顺序是判据逼出来的：第一版先 `is_dir()`，
`根B\..\别处` 这种越界路径被读成「目标不是目录」—— 报错话术把越界盖住了。测试先行先红，
才把这两句对调。

**判据**：Rust 4 条新用例（跨根复制 / 跨根移动 / 拿错锚点仍拒 / 空锚点拒 + `..` 逃逸拒且
盘上什么都没创建）；原 B315 那 4 条改成四参仍绿 ⇒ 同层行为一个字没变。

**真机**（S1/S2）：A 的 `alpha.md` → Ctrl+C → B 的 `inbox` → Ctrl+V：盘上出现、字节一致、源还在；
`moved-针.md` 先开着再 Ctrl+X → Ctrl+V：源消失、目标出现。随后**在编辑器里打一个 `Z` 并 Ctrl+S**：
新位置的文件里有 `Z`、旧位置没有被重新创建 —— 「打开中的文档跟着改」只有这一发判得死
（只看标签名的话，旧路径坏没坏根本看不出来）。

## B427-2 · 顶部过滤框

**口径**（逐条照拍板）：全量匹配（含从没展开过的层）→ 结果**仍画成树** → 框内带排除/忽略两颗
开关（与侧栏搜索同一套）→ 清除键 + 框内 Esc 清字。

**Rust `filter_tree`**（`src-tauri/src/commands/search.rs`）：

- 只匹配**名字**，不读文件内容 ⇒ 大仓库不按字节数付费；
- 匹配器复用 `build_matcher`（字面/正则、大小写、全词 `is_word_char`）；
- 排除层复用 `push_ignores` / `is_ignored` / `is_noise_dir`，点文件跳过；
- **没命中的目录照样下去** —— 这就是「全量匹配」与「树状展开」的接缝；
- 上限 `MAX_NAME_HITS = 1000` / `MAX_NAME_NODES = 50_000`，撞了回 `truncated = true`，
  面板如实说「只显示前 1000 条（把查询写细一点）」。

**自审抓到的缺口**：按钮叫「使用排除设置与忽略文件」，第一版只跳点文件/噪声目录/`.gitignore`，
**没吃设置页那串 `search_exclude`**。侧栏搜索的同一发是
`mergeGlobs(query.useExcludes ? settings.search_exclude : "", …)`；过滤框补上 `exclude` 参数，
在面板同一处按同一道总闸取值，Rust 只认「给什么挡什么」（两层各管各的，不做第二张判据表）。

**前端 `src/explorer/filter.ts`**：后端回的是一串 posix 相对路径的命中 ⇒ 这里合成祖先链
（不逐层 `list_dir`）、按自然序排（与 Rust 的 `natural_cmp` 同口径）、`visibleOf` 按 depth 在
DFS 序里藏子树；过滤态的折叠册 `filterCollapsed` **与常规树的 `expanded` / `rootsCollapsed` 分家**
（清空过滤不该带走常规树的折叠）。

**面板 `src/explorer/panel.ts`**：单飞 `filterSeq`（后发先至只认最新）+ 180ms 去抖 + 回车立即；
行构建抽成 `rowOf`（常规树与命中树共用一份，不造第二张布局判据）；过滤态里拖动高亮实时重贴；
`onExplorerChange` 在过滤中补一发重跑（刚粘进来的名字立刻出现）。

**真机**（S3）：`针` 命中第三层 `deep/deeper/深处针.md`（常规树从没展开过这一层）、两根各画各的段；
`hidden/`（`.gitignore`）、`excl/`（设置页排除串）、`node_modules/`（噪声）三层默认都挡；
关「排除」三层一起放开；只关「忽略」时**只有 `.gitignore` 那层**放开（excl 与噪声仍挡）；
全词 `ping` 去掉 `pingpong.md`、大小写 `Note` 只剩 `Note.md`、正则 `^(Note|NOTE)\.md$` 命中两份；
清除键有字才显形、点一下回常规树；Esc 在框里清字。

## B427-3 · 三颗搜索键的提示

**根因**：那三颗 `.find-toggle` 在 `index.html` 里只有 `aria-label`，没有 `data-tip` ——
自绘提示层只认 `data-tip`（与 `setTip` 写进去的是同一个字段），所以悬停什么都不出。
补上 `data-tip`（与 `aria-label` 同文，B350 的两档口径：按钮档）。过滤框里新增的六颗
（三颗匹配 + 排除 + 忽略 + 清除）一并带上。

**判据**：`tests/tooltip-classes.test.ts` 新增「侧栏搜索里每一颗 `.find-toggle` 都自带提示」
普查（≥5 颗、全带 `data-tip`、与查找条按图标名配对）+ 一条 id 锚定的反向自测；
真机 S4 悬停 0.5s 后读 `.tooltip-text`：区分大小写 / 全词匹配 / 使用正则表达式，逐字对上。

## 真机台

`.tmp/b427-probe.py`：**73 PASS / FAILS=0**。台子自己坑了四次（都记下来，别再犯）：

1. **点目录行会整树重建**（`activateDir` → 读盘 → `renderTree`）⇒ 刚点的那颗 DOM 没了、焦点掉回
   `body`，随后 Ctrl+V 落在 body 上什么都不发生 —— 第一轮三个 FAIL 全栽在这。修：点击后
   **重新聚焦那一行**再发键。
2. **名字判据会说谎**：`alpha.md` 本来就在 A 根里，按名字等 `alpha.md` 的断言在粘贴失败时照样绿。
   修：按**完整路径**等行（`data-path === …`）。
3. `#explorer-filter` 这个选择器根本不存在 —— 那是 class 不是 id，判据读到 `null` 报 FAIL。
4. `.tooltip-text` 是一句纯文本，不该走 `json.loads`（第一版直接抛 JSONDecodeError）；
   另外 `notes` 目录名本身含 `note`，大小写不敏感时是一条**合法命中**，期望名单要带上它。

## 留下的口子（照实说）

- 过滤框的「排除」总闸关掉时，设置里的持久排除也一起失效 —— 与侧栏搜索一致（同一句话：
  那颗闸同时管「排除设置 + 忽略文件」）；「忽略」只关 `.gitignore` / `.ignore` 这一层，
  点文件与 `node_modules` 那类噪声目录仍归总闸。
- 过滤是**一次整棵扫**（每根一发 IPC）。大仓库第一次敲键有一次可感的延迟；单飞只保证
  「旧结果不许盖新结果」，没有做增量与取消。
- 过滤结果里目录的展开/收起是**纯视图**的（命中树已经全在手里），不读盘、也不写常规树的展开缓存；
  清空过滤后常规树回到原来的折叠状态。
- 跨根粘贴到**根那一行**走的是同一发（目标是根时锚点就是它自己），真机台只验了「粘到子目录」；
  根那一路由 Rust 单测的 `two_roots` 覆盖。
- 大小写/全词/正则在**名字**上匹配，不是路径 —— 与搜索框对内容的匹配是两把尺子，功能语义如此。
