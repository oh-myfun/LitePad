## ① 要什么（用户口径，逐条原样）

- 「复刻vscode的文本差异编辑器，在左侧边栏添加按钮和面板，面板中显示差异编辑器中的差异项，
  编辑器尽量复刻vscode原有能力，包括标签栏对应的按钮。」
- 设计稿（`docs/superpowers/specs/2026-11-05-diff-editor-design.md`）落定的形态：差异是**独立标签类型**，
  并排两栏；右栏就是那份文档本身（脏点 / Ctrl+S / 标签原点全归它），左栏是只读对照物；
  A 档「与上次保存比较」+ B 档「任意两文件比较」；侧栏第五块按**块**列差异项，点一条两侧同时落位。

## ⑤ 过程中抓到的真病灶（都已修）

1. **产品 · 第五块装配即白板**（真机 A-00）：`setDrawer` 的 boot 回放调 `onShow` 时视图还没登记，
   `registerDrawerView` 又只管显隐 ⇒ 还原出来的「差异」块列表为空。修：`setupDiffPanel()` 末尾补
   `updateDiffDrawer()`（`94cc8ac`）。红测：`tests/diff-panel.test.ts`「装配那一刻就画」先红
   （`expected '' not to be ''`）。
2. **产品 · 关差异标签把原标签带到差异栏的滚动位置**（真机 A-61/A-63）：差异右栏被当成
   「同文档的另一个视口」进同步在册，`Ctrl+End` 一发被判成用户滚动并**外发**
   （日志 `12:58:24 … 外放 doc=1 v=33.00`），接班标签 `scrollV` 被改写，关标签后原标签停在
   664.7px。按设计稿反目标（「sync-scroll 的语义是同一文档两个面板，这里是两份内容」）+
   ⑦⑥：差异标签**不进**同步滚动在册（`wire.ts` 的 reconcile 按 `kind === "diff"` 跳过，
   `557a6b9`）。红测先红（`currentV("100")` 非 null）；R25 那条「用户滚动仍广播」的反向闸
   按新语义改判为「差异面也不广播」，普通标签那张反向闸留在 `sync-scroll-sequence.test.ts`。
3. **台子四处自伤**（都不改产品）：`MOD_ALT=2` 错（CDP Alt=1、Ctrl=2 ⇒ 上一轮发成了 Ctrl+F5
   硬重载）；点完面板条目后 `Ctrl+Home` 落在按钮上（前置先 `.cm-content.focus()`）；
   块计数按单帧快照（CM6 只渲染视口附近 ⇒ 改成滚动扫掠取去重并集）；RAF 时间戳本来就是毫秒，
   打点又乘了 1000（C-12/C-13/C-22 假红，真值 16.7ms）。另有一次 C 浅色大文件 120s 超时
   是前台抖动，原样重跑 515ms 通过。

## ⑥ 已知限制（本轮没做的，逐条点名）

- **内联（单栏）视图**不做；`Diff View`（并排⇄内联）子菜单不做（设计稿 ④·7）。
- **逐字符 `innerChanges`** 不做：只到行级（行内改了什么靠肉眼比对，不画字符级高亮）。
- **移动代码块**按「删除 + 插入」呈现，不识别为 move。
- **多文件差异编辑器**不做（B 档是一对一）。
- 差异标签**禁止**跨面板 / 跨窗口搬移（Task 10 的边界闸；拖拽整组缺席而不是置灰）。
- 「折叠未改动区」**不是用户设置项**：默认不折，三颗动作（折叠 / 展开 / 全部）现点现用。
- **面板虚拟滚动不做**：见 ⑧ 的实测 —— LCS 预算把块数上限定在约 250，两百块列表滚动不掉帧。
- 大文件里**改动跨度很大**时会退化成「整段一块」（对齐器 LCS 预算 250k 的退化路径，与 B458
  的 4px gutter 同源）：实测 340,887 行文档、5 处分散改动 ⇒ 1 块（单算 22–34ms）。
- **左栏 4px 指示带贴的是行盒右沿**：长行不折行（R19）时行盒比视口宽，横滚到 0 时这条带在
  视口外（行底色仍在）；短行（B 档截图）它就贴在分屏线一侧。要做成 VS Code 那种「永远贴视口
  边」需要独立覆盖层，本轮不做。
- 打开差异标签时两栏是两条独立 scroller，**初始视口不保证逐行对齐**；点条目 / 步进会两侧
  同时落位（②按落位后判）。

## ⑦ 计划替用户做的决定（供核对）

- 不做额外并块：隔一行未改动就是两块（与 VS Code `LineRangeMapping` 同形）。
- A 档不可 `swapSides`（左栏是「上次保存」，换过来语义不成立）。
- 差异实例不画 B458 的 4px 列（那一列只属于原标签；也不进 gutter）。
- 两张差异标签都进会话（关窗重开还在，含 B 档的左文件路径）。
- 侧栏按钮列次序：搜索之后（第五块）。
- 基线未知时用「置灰 + 文案自述」代替 tooltip（`BASELINE_UNKNOWN_MESSAGE`）。
- 文案纪律：「复刻」字样不出现在界面；空态说清「为什么空」。
- 本轮新增：差异标签不参与同步滚动（R54，见 ⑤·2）；第五块装配即画（见 ⑤·1）。
