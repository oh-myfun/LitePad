## ① 要什么（用户口径，逐条原样）

- 「源码模式中：文件修改未保存时，在行号区域用颜色标注一下 diff 情况，样式类似 notepad++，
  在代码行折叠符号右边绘制一条标注（4px 宽正好和目前预留空间匹配，红色删除，绿色添加，橙色修改）」
- 基线取「**上一次保存的正文**」（`doc.baseline`，与标签上那颗未保存原点同一个值），不是 git HEAD
  ⇒ 保存之后整片清空。
- 「B，但是示例的位置不对，如果是 4 行后面的行（原先的 5、6 行）删除了，红条就应该画在 4 行和
  5 行中间，另外如果此时 4 行也被修改了或者 5 行处插入新增的行，红条不能被 4 行的黄色和 5 行的绿色遮挡。」
- 「按照方案 A 实现，先看最终实际效果，方案 C 做备选」⇒ 方案 C（红珠描 1px 边）**没做**，留作备选。

## ⑤ 过程中抓到的两条真病灶（都已修）

1. **产品**：混合区（既删又改）时红缝掉到下一格。根因 = 替换区按下标顺序配对，把被删块的第一行
   当成了被改的那一行。修法 = `alignOffset` 按「公共前缀+后缀」的相似度给少的那侧挑错位。
   第一版又踩一坑：`span` 拿 `short.length`（整个中段的行数）而不是**本区**的行数 ⇒ 中段另有一处改动时
   span 算成负数 ⇒ 静默退回老口径，而原单测恰好挑不出（那条里两个数相等）。补了显式 `shortLen`
   和一条能区分的判据（`lineDiff("A1\n甲线\n乙\n丙一去\n丙二来\n丁后行\nZ", …)`，先看它红）。
2. **台子**：⑨ 那段曾经「零卡顿且没标记」是假绿 —— `Input.dispatchKeyEvent` 只发 `rawKeyDown/keyUp`
   时 WebView2 不产生 char/input 事件，12 发物理键全打在空气里；再加上「第一发点击被 CM6 先聚焦编辑器
   拿走」。修法 = 可打印字符显式带 `text`、点击补一发，并把判据改成量**打了字的那一行本身**
   （原先拿 `.cm-content` 的 textContent 跟整篇 3MB 比长度，得出 -2658886 这种荒唐数）。
   之前报的「3MB 中位 16.60ms」因此不算拿到过同尺结论，本轮才是真数据。

## ⑥ 已知限制 / 备选

- 多行删除只画**一道**缝，不随删除行数变长（用户口径「先看实际效果」）。
- 方案 C（红珠 + 1px 描边）未实现，作为遮挡观感不满意时的备选。
- 大文档的缝/色只在**视口内**那些格上画（CM6 gutter 只渲染视口行）；滚过去会跟着补画。
- 基线未知（副本还原 / 跨窗口认领）时整片不画，保存一次即恢复。
- 台子的 ⑨ 只测「连打 12 发 + 停下那一次」，没测「全选粘一篇」那种整篇换掉的退化路径（纯函数侧有 2000 行的用例兜着）。

## ⑦ 续轮（同日）：明暗同一套色 + 红加深

用户看完真机截图后提两条：「浅色模式的色条应该和深色一样（现在的看起来像绿色）」+「删除的红色颜色统一加深一下」。
中间还试了一轮「红色改右指等腰三角」（出了三张样稿：色条三方案 / 右指三角六画法 / 高 8px 宽度四档），
最后定稿 **仍用竖条**，只改颜色。

- **根因**：橙那颗借用了全应用的 `--warn`，浅色档它是**橄榄绿** `#667309`（给警告**文字**用的），
  与绿那颗 `#587c0c` 几乎同色 ⇒ 浅色档「橙看起来像绿色」。
- **改法**：三颗收进**主题无关的 `:root`**，只定义一次 —— `--diff-add #72c892`、`--diff-mod #e5ba7d`、
  `--diff-del #e5534b`（红由 `#f48771` 加深）。五族明暗基座表与族覆盖块里这三颗**全部删除**；
  `--warn` / `--danger` 本身不动（它们还服务全应用警示色，改了会带动别的界面）。
- **契约**（`tests/gutter-diff-style.test.ts` 十条，先看它红 7 条再落地）：三颗在十个变体下解析到同一值、
  不许出现在基座表/族覆盖里、橙与红的规则体不许再写 `var(--warn)` / `var(--danger)`、
  并用 **sRGB 相对亮度**判「加深」这一条不许悄悄退回去（不看字符串像不像）。
- **真机**：深色 / 浅色各 **38 判定 FAILS=0**，页面现读的三颗两档完全一致
  （绿 `rgb(114,200,146)` / 橙 `rgb(229,186,125)` / 红 `rgb(229,83,75)`）；
  全量门禁 132 文件绿、lint + format 绿、release exe 重出（21:40）。
- 顺带：台子 `JS_TOKENS` 改读这三颗 diff token（原来读 `--warn`/`--danger`，借色一断就判错对象）。
