# B405 · 编辑模式：切块恢复 / 语言按钮搜索 / 列表符点显形

用户（2026-10-29）：

> 继续优化编辑模式：1、光标从markdown块切换到html块时，markdown块没有变回渲染样式（再点另一个markdown块能够正常变回）。2、代码块的语言选择下拉组件改成按钮样式，展开列表支持搜索，不要和行号竖线重叠（可参考vditor的代码块设计），且要显示在所有组件之上（目前会显示在下拉组件之下）；3、任务列表项进入编辑状态时，前面的-线也要能看到并支持编辑；4、无序列表项的符号也要和任务列表项一样对齐在对应项首行

另：

> 编辑模式：无序列表项的符号也要能在光标激活变回编辑状态时切回显示短线-。

## 一、切块后上一块没恢复渲染

块级就地编辑用的是**组件自己的 contenteditable**，焦点搬家不经过 CodeMirror ⇒ 编辑器选区
还停在上一个块上，`visible` 装饰不重建，上一块就一直停在显形的源码态。修法：`focusin` 进块内
编辑区时把选区停到这一块起点（`editableSource.ts#parkSelectionAtBlock`，只 `dispatch` 选区、
不 `view.focus()`，块里的光标不受影响）。再点另一个 markdown 块能恢复，是因为那一下走了 CM。

## 二、代码块语言控件：工具行按钮 + 可搜索 + 顶层弹层

- 块结构拆成 `.md-codeblock-header`（工具行）+ `.md-codeblock-body`（行号栏 + 代码区），
  语言按钮与复制键并排放在工具行右侧 —— 照 vditor，列表与按钮都不再压行号竖线；
- 下拉加 `searchable: true`（「搜索语言…」），与设置页字体/语言下拉同一套；
- 列表展开时**挂到 `document.body`**：编辑器里 `.cm-scroller` 带 `z-index: 0` 的层叠上下文，
  留在 DOM 里无论 z-index 多高都压不过外壳与其它组件；关闭时收回触发器（关闭态结构不变）；
- 贴着视口右缘展开会溢出 ⇒ `positionList()` 右侧放不下往左收；
- 列表自己挡 keydown 冒泡（冒泡阶段），别把按键漏给全局快捷键。

## 三、任务行 `-` 与无序列表符点

- `ListMark` 的 hide 装饰原先用 `NEVER_REVEAL`（永不显形），现在与 `TaskMarker` 一样带
  **所属行范围**的 reveal 窗口 ⇒ 光标压住这一项时 `- [ ]` / `1.` 整段源码显形、可直接编辑；
- `revealMarkerLine` 从 `TASK_LINE_RE` 扩到**任意列表项**（`[-*+]` 或 `\d+[.)]`），CSS 用
  `.md-list-item.md-reveal-marker` 收掉 `::before` 与标记槽左内距（行内 indentStyle 特异度
  高，这一条必须 `!important`）；
- 无序符点对齐首行：行内 `::before` 的 `top: 50%` 会把符点放到**整块**中段（折行项悬在
  第二三行），改成 `top: calc(var(--editor-line-height, 1.5) * 0.5em)`。

# B406 · 编辑模式：本地图片路径 / 图片块两种编辑入口

用户（2026-10-29）：

> 编辑模式：1、本地路径png图片无法正常显示；2、图片块要支持编辑，同时支持点击图片编辑代码、添加悬浮编辑按钮点击打开编辑弹窗（参考inknote）两种方式。

## 一、本地图片路径收口（`spike/deco/assets.ts`）

三个叠加的病灶：

- `../pics/x.png` 原样拼给 Tauri 资产协议 —— **协议拒绝含 `..` 段的路径** ⇒ 显示不出来；
- `file:///C:/...` 被当成相对路径拼到文档目录后面；
- UNC `\\server\share\x.png` 与 `\\?\` 设备前缀同样被当相对路径。

重写 `resolveAssetPath`：`fileUrlToPath`（先百分号解码再去盘符前导斜杠）、`stripDevicePrefix`
（`\\?\` / `\\.\` / `\\?\UNC\`）、`normalizeSegments`（折叠 `.` / `..`，越过根就夹住）、
`isAbsolutePath`（盘符 / UNC / 前导斜杠）判定后才拼文档目录。

配套：`markdown.ts#refreshDecoAssetBases()` 挂进 `ui.refreshAll`（`main.ts` 注入）——保存 /
另存为 / 重命名后 `assetBase` 跟着文档路径走，图片基准不会停在旧地址。

## 二、图片块两种编辑入口（`spike/deco/imageWidget.ts` + `shell/imagedialog.ts`）

- **点图片 ⇒ 就地显形源码**：`imageReveal` 的窗口取 `from+1 .. to-1`（两端各让两个字符：
  文档打开时选区在 0、键盘越过原子块停在 `to`，这两种并非想编辑的落点不许让图片一打开就
  变源码）；点击把选区送到 `from + 2`（alt 起点）；`atomicRanges` 对**光标已在块内**的块不再
  算原子区间，否则点选/方向键被「整块跳」吞掉；
- **悬浮编辑按钮**（图右侧、框外，26px codicon，只读档隐藏）打开应用内弹窗：alt + 路径 +
  原生浏览键；Enter 提交、Esc 取消、空路径禁用确认；确认后按 `imageMarkdown()` 重写这一块
  （alt 转义 `]`/`\`，路径含空格/括号/`<`/`>` 用 `<...>` 包，标题转义 `"`/`\`）；
- 弹窗沿用 `.settings-overlay` + `.settings-dialog image-dialog`，挂 body；浮层不是 flex ⇒
  对话框用 fixed + translate 显式居中；
- 加载失败：错误框画在图片框内（虚框），路径提示藏起来。

真机抓到一条：按钮原先压在图中央（26px 按钮盖 32px 小图）⇒ 点击图片命中按钮、弹窗乱开。
修法是把按钮放到图片框**右侧外部**（`left: calc(100% + 8px)`）。
